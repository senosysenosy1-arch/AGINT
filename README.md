# المرحلة 0 + 1 — ربط واتساب + محادثة ذكية بـ Claude API و MySQL

## إيه اللي اتضاف في المرحلة 1؟

- `db.js` — الاتصال بقاعدة بيانات MySQL، وإنشاء جدول `messages` تلقائيًا،
  وحفظ/جلب رسايل كل محادثة.
- `claude.js` — استدعاء Claude API بشخصية المساعد (`SYSTEM_PROMPT`) + سياق
  المحادثة، وإرجاع رد نصي.
- `index.js` — بقى بيربط الاتنين: كل رسالة واردة على واتساب بتتحفظ، بتتبعت
  مع آخر 20 رسالة كسياق لكلود، والرد بيتحفظ ويترجع للشخص على واتساب.

## الإعداد

### 1. المتغيرات البيئية

```bash
cp .env.example .env
```

افتح `.env` واملأ:
- `ANTHROPIC_API_KEY` — من [console.anthropic.com](https://console.anthropic.com)
- بيانات الاتصال بـ MySQL (`DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`)

### 2. قاعدة بيانات MySQL — إيه الخيارات؟

**للتجربة محليًا:** لو عندك MySQL متثبت على جهازك أو عن طريق Docker:
```bash
docker run --name whatsapp-mysql -e MYSQL_ROOT_PASSWORD=secret \
  -e MYSQL_DATABASE=whatsapp_assistant -p 3306:3306 -d mysql:8
```
وبعدها `DB_HOST=localhost`, `DB_USER=root`, `DB_PASSWORD=secret`, `DB_SSL=false`.

**لقاعدة بيانات سحابية مجانية (مفيش كارت ائتمان مطلوب):**
**Aiven for MySQL** بيدي خطة مجانية دايمة (مش تجربة محدودة بوقت): 1 جيجا تخزين،
1 جيجا رام، نسخ احتياطي تلقائي، من غير كارت ائتمان. ملحوظة مهمة: الخدمة بتتقفل
تلقائيًا لو فضلت من غير استخدام لفترة، وبيبعتولك إيميل تنبيه قبل كده — يعني
مناسبة للتطوير والتجربة، لو المشروع استقر انتقل لخطة مدفوعة أو لقاعدة بيانات
على نفس الـVPS بتاع هوستنجر.

سجّل في [aiven.io](https://aiven.io) وأنشئ خدمة MySQL، وهتلاقي `DB_HOST`,
`DB_PORT`, `DB_USER`, `DB_PASSWORD` جاهزين في لوحة التحكم — وحط `DB_SSL=true`.

### 3. التشغيل

```bash
npm install
npm start
```

هيظهرلك QR code — امسحه من واتساب (الأجهزة المرتبطة ← ربط جهاز).
بعد كده جرب تبعت رسالة من رقم تاني لرقمك، ومن المفروض كلود يرد عليك، ولو
بعت تاني هيفتكر اللي قلته قبل كده لأن السياق بقى محفوظ في قاعدة البيانات.

## المرحلة 2 — التذكيرات (الجديد)

### إيه اللي اتضاف؟

- **جدول `reminders`** في MySQL (بيتنشئ تلقائيًا أول تشغيل): كل تذكير فيه
  نص الرسالة، الميعاد، ومين هيتبعتله.
- **`claude.js`** بقى فيه أداة (tool) اسمها `create_reminder` — كلود نفسه
  بيقرر إمتى يستخدمها لما يفهم من كلامك إنك عايز تتفكّر بحاجة، وبيحسب
  الميعاد الفعلي حتى لو قلت "بعد نص ساعة" أو "بكرة الصبح" (بنمرّره الوقت
  الحالي بتوقيت القاهرة في التعليمات، وهو بيحسب الباقي).
- **`reminders.js`**: scheduler بـ node-cron بيفحص الجدول كل دقيقة، ولو لقى
  تذكير وقته جه بيبعتلك رسالة واتساب تلقائية 🔔.
- **`utils.js`**: دالة بسيطة لحساب الوقت الحالي بتوقيت القاهرة، مستخدمة في
  أكتر من مكان عشان التوقيت يفضل متسق.

### جرّبها إزاي

ابعت رسالة زي:
> فكّرني بعد 5 دقايق أشرب مية

كلود هيرد بتأكيد ("تمام، هفكّرك بعد 5 دقايق")، وبعد 5 دقايق بالظبط
(الـscheduler بيفحص كل دقيقة) هتيجيلك رسالة "🔔 تذكير: ...".

### حاجة تستاهل الانتباه لها

لو مشغّل المشروع على Render الخطة المجانية، السيرفر ممكن "ينام" لو مفيش
طلبات HTTP بتوصله لفترة (الـwebsocket بتاع واتساب لوحده مش دايمًا كافي
يخليه صاحي حسب سياسة المنصة). يعني لو حد حجزلك تذكير والسيرفر نايم وقتها،
هيتبعت متأخر لما السيرفر يصحى، مش هيضيع خالص (لأنه بيتسجل في قاعدة
البيانات أول ما يتطلب)، بس التوقيت مش هيبقى دقيق 100% لحد ما تنقل لاستضافة
شغالة 24 ساعة زي VPS هوستنجر.

## تحديث: استخدام قاعدة بيانات هوستنجر بدل خدمة خارجية

لو عندك استضافة ويب على هوستنجر أصلاً (زي خطة Premium/Business)، تقدر تستخدم
قاعدة بيانات MySQL بتاعتها بدل Aiven — هي متضمنة في الاستضافة من غير أي
تكلفة إضافية، وده أبسط وأوفر. سيرفر Node.js (Baileys) لسه محتاج يتحط على
استضافة تانية دايمة الاتصال (Render / Google Cloud e2-micro) لأن الاستضافة
المشتركة العادية مش مصممة تشغّل عملية خلفية دايمة الاتصال زي كده.

### خطوات التفعيل

1. من **hPanel → Databases → MySQL Databases**: أنشئ قاعدة بيانات ومستخدم
   جديدين (لو مش عندك أصلاً).
2. من نفس القسم دور على **Remote MySQL**، وضيف IP السيرفر بتاع Node.js
   (لو مش عارف الـIP لسه وقت التجربة، تقدر تحط `%` للسماح بالاتصال من أي
   IP مؤقتًا — بس لما المشروع يستقر رجّعها لـIP محدد بس لدواعي الأمان).
3. في ملف `.env` بتاعك:
   - `DB_HOST` = عنوان IP أو hostname الاستضافة بتاعتك (مش `localhost`)
   - `DB_USER`, `DB_PASSWORD`, `DB_NAME` = زي ما أنشأتهم في الخطوة 1
   - `DB_SSL=false` (هوستنجر عادة من غير SSL على القواعد المشتركة)
4. شغّل `npm start` عادي — الكود مش محتاج أي تعديل، بس بيقرا القيم من `.env`.

**ملحوظة أمان:** خلّي `%` (السماح لأي IP) مؤقتة بس وقت التطوير. أول ما
تعرف الـIP الثابت لسيرفر Render أو Google Cloud بتاعك، رجّع القيمة لـIP
محدد بدل `%` عشان محدش غريب يقدر يوصل لقاعدة البيانات.
